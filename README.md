# ScreenPin

Небольшое приложение для Windows: выделите область экрана, чтобы закрепить её снимок поверх других окон. Можно открыть несколько снимков, двигать их, менять размер и сохранять в PNG.

## Запуск готовой версии

Запустите `ScreenPin-Windows.exe`: его можно переносить отдельно, нужная библиотека встроена в файл. Также можно распаковать архив с инструкцией и лицензией. Приложение сразу работает в фоне и доступно через значок в области уведомлений Windows. Нужен Windows и .NET Framework 4.x. Установка Python не требуется.

1. Нажмите `Ctrl + Shift + 2` или выберите «Новый снимок» в меню значка ScreenPin в трее. Сочетание по умолчанию можно изменить в настройках.
2. Выделите прямоугольник мышью. `Esc` отменяет захват.
3. Перетаскивайте снимок мышью. Потяните за нижний правый угол для изменения размера или щёлкните по снимку и используйте колесо мыши. `Alt` + колесо меняет прозрачность, в диапазоне от 25% до 100%.
4. Наведите курсор на снимок: появится полупрозрачная панель с кнопками `−`, `+`, булавкой, сохранением в PNG и закрытием. Булавка блокирует перемещение и изменение размера, включая колёсико и кнопки `−`/`+`; прозрачность через `Alt` + колесо остаётся доступной. Повторное нажатие снимает блокировку. Снимки скрыты из списка Alt+Tab. Изображение при сохранении в PNG остаётся исходным, без прозрачности и скругления окна.
5. Откройте «Настройки» через меню значка в трее. Нажмите поле горячей клавиши, затем желаемое сочетание с `Ctrl`, `Shift` или `Alt` и буквой, цифрой либо `F1`–`F11`. Нажмите «Сохранить». Если клавиша занята, предыдущая комбинация останется активной. Выбранное сочетание сохраняется в `%APPDATA%\ScreenPin\hotkey.txt`.
6. В меню трея можно включить или отключить автозапуск и полностью выйти из приложения. Автозапуск по умолчанию выключен. Если предыдущая версия уже была добавлена в автозапуск, выберите «Обновить автозапуск для этой версии» после перемещения новой версии в постоянную папку.

Если горячая клавиша уже занята, приложение сообщит об этом — используйте меню в трее. Закройте предыдущую версию перед запуском новой, поскольку одновременно работает только одна копия. Снимки хранятся в оперативной памяти и пропадают при закрытии, если их не сохранить вручную. Мультимониторный режим и масштабирование Windows требуют дополнительной проверки на разных конфигурациях.

## QR-коды

- Выделите ссылку или другой текст целиком и нажмите `Ctrl + Alt + 1`. ScreenPin скопирует выделение в буфер обмена и покажет QR-код; предыдущее содержимое буфера будет заменено. В окне можно скопировать изображение, сохранить PNG или перетащить картинку прямо в приложение, поддерживающее перенос файлов. Некоторые чаты потребуют отдельно нажать кнопку отправки. При перетаскивании создаётся временный PNG в `%TEMP%\ScreenPin\qr-drag`; он остаётся там до очистки временных файлов Windows.
- В адресной строке браузера можно нажать `Ctrl + L`, затем `Ctrl + A`, чтобы выделить адрес целиком; после этого нажмите сочетание для создания QR. Если копирование не сработало, скопируйте адрес через `Ctrl + C` и выберите «QR из буфера обмена» в трее.
- Нажмите `Ctrl + Alt + 2` и выделите область с QR-кодом, включая белые поля. В окне результата можно скопировать содержимое или открыть ссылку `http://` / `https://`, выбрав браузер по умолчанию или обнаруженный Chrome, Edge, Firefox либо Brave. Другие типы содержимого доступны для копирования.
- Оба сочетания можно изменить отдельно в пункте «Настройки QR» меню в трее или через кнопку «QR · настройки» в главном окне. Если приложение, из которого копируется текст, не позволяет перехватить выделение, скопируйте текст обычным `Ctrl + C` и выберите «QR из буфера обмена» в меню трея.

Создание и чтение QR-кодов выполняется локально, без онлайн-сервисов.

## Сборка из исходников

В CMD перейдите в каталог проекта и выполните `build.cmd`. Скрипт использует компилятор .NET Framework, входящий в Windows, и создаёт самостоятельный `dist\ScreenPin.exe` со встроенной библиотекой и отдельным файлом её лицензии. Папка `dist/` исключена из Git.

Для работы с QR используется [ZXing.Net 0.16.11](https://github.com/micjahn/ZXing.Net) по лицензии Apache 2.0; копия лицензии находится в `lib/ZXING-LICENSE.txt` и в архиве приложения.

## Версия для Mac

Версия для macOS находится в папке [`macos/`](macos/README.md). Она собирается отдельно для Apple Silicon и Intel; это приложение для Mac, а не для iOS.
