# ScreenPin

Небольшое приложение для Windows: выделите область экрана, чтобы закрепить её снимок поверх других окон. Можно открыть несколько снимков, двигать их, менять размер и сохранять в PNG.

## Запуск готовой версии

Распакуйте архив в любую папку и запустите `ScreenPin.exe`. Приложению нужен Windows и .NET Framework 4.x. Установка Python не требуется.

1. Нажмите «Выбрать область» или `Ctrl + Shift + 2`.
2. Выделите прямоугольник мышью. `Esc` отменяет захват.
3. Перетаскивайте снимок за изображение, изменяйте размер за края окна или колесом мыши. Кнопки `+` и `−` тоже меняют масштаб.
4. Кнопка со стрелкой сохраняет исходный снимок в PNG, `×` закрывает его.
5. Закрытие главного окна прячет приложение в трей. Для полного выхода используйте «Выход» в меню значка в области уведомлений.

Если горячая клавиша уже занята, главное окно сообщит об этом — используйте кнопку или меню в трее. Снимки хранятся в оперативной памяти и пропадают при закрытии, если их не сохранить вручную. Мультимониторный режим и масштабирование Windows требуют дополнительной проверки на разных конфигурациях.

## Сборка из исходников

В CMD перейдите в каталог проекта и выполните `build.cmd`. Скрипт использует компилятор .NET Framework, входящий в Windows, и создаёт `dist\ScreenPin.exe`. Папка `dist/` исключена из Git. Готовый исполняемый файл и исходники должны распространяться как отдельный архив релиза.
