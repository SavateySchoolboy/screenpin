# ScreenPin для macOS

Приложение работает в строке меню и позволяет закреплять снимки экрана и работать с QR-кодами. Сборки предназначены для macOS, а не для iPhone или iPad.

- По умолчанию `⌘ + ⇧ + 2` выделяет область экрана и закрепляет её поверх других окон.
- `⌘ + ⌥ + 1` создаёт QR из выделенного текста; `⌘ + ⌥ + 2` считывает QR из выделенной области. Сочетания можно изменить в настройках.
- Наведите на снимок, чтобы открыть панель. Снимок можно перемещать, масштабировать колёсиком, сохранять, закрепить от случайного перемещения и масштабирования; `⌥` + колесо меняет прозрачность.
- Созданный QR можно скопировать, сохранить или перетащить в совместимый чат. Считанную ссылку можно скопировать или открыть в выбранном браузере.
- При первом использовании система может попросить доступ к записи экрана, универсальному доступу и автоматизации. Разрешения управляются в настройках macOS. Буфер обмена заменяется при копировании выделенного текста.

## Сборка

На Mac установите Node.js 22, затем выполните `npm ci`, `npm run check`, `npm run build:mac`. Готовые `.dmg` появятся в `dist/`: `arm64` для Apple Silicon и `x64` для Intel. Проект также собирается в GitHub Actions на macOS. Версии без Developer ID и нотариального заверения Apple могут потребовать подтверждения в настройках безопасности macOS и не гарантируют беспрепятственного запуска на чужом Mac.

Приложение использует Electron, QRCode и jsQR; обработка QR локальная. Полное ручное тестирование захвата экрана, системных разрешений и перетаскивания должно выполняться на macOS.
